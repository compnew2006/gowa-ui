## Overview

The Chat Workspace is where agents read conversations, send replies, review media, and manage chatbot handoffs. It combines real-time updates, rich WhatsApp message rendering, and quick agent actions in a single conversation view.

## Message Bubble Behavior

The chat view renders message content according to its WhatsApp message type:

- **Text messages** display standard text bubbles.
- **Media messages** show inline previews when media is available and fall back to captions when present.
- **Button replies** display the selected reply in a dedicated bubble style.
- **Interactive CTA URL messages** show a separate call-to-action button.
- **Location and contact messages** render as structured cards instead of raw JSON.

<Aside type="tip">
  Template previews in the send dialog use the same link-aware text rendering as chat bubbles, so agents can verify URLs before sending.
</Aside>

## Clickable Internet Links

When a message bubble contains an internet link, the chat workspace automatically turns it into a clickable anchor.

### Supported Link Formats

- `https://example.com/path`
- `http://example.com/path`
- `www.example.com`
- bare domains such as `portal.example.com/help`

### Rendering Rules

- Links inside text messages, button replies, and text captions become clickable.
- Links open in a new browser tab.
- Trailing punctuation like `.`, `,`, `!`, `?`, or unmatched closing brackets stays outside the clickable area.
- Email addresses such as `support@example.com` remain plain text.
- Links inherit the message bubble color styling and include a visible keyboard focus state.

## Sending a Template with Link Preview

<Steps>

1. Open the chat for the target contact.

2. Choose a template from the template picker.

3. Fill in any required template parameters.

4. Review the preview bubble.

   If the rendered body contains internet links, they appear as clickable links in the preview before you send.

5. Send the template once the preview looks correct.

</Steps>

## Agent Workflow Notes

- If a conversation is transferred to an agent, chatbot processing pauses for that contact until the transfer is resumed.
- Multi-account chats can show account-specific context so the agent can respond from the correct WhatsApp source.
- Message status icons continue to show sent, delivered, read, or failed states independently of link rendering.
- Multi-file attach keeps the current media delivery path and queues one outbound media request per selected file, so delivery logs and existing API integrations stay compatible.

## Best Practices

1. Include the full destination when sending links so agents and customers can validate where the link goes.
2. Prefer `https://` links when possible.
3. Review template previews before sending parameterized URLs.
4. Keep captions concise when attaching media and links in the same message.
5. For multi-file sends, remove any unneeded attachment in the preview dialog before submitting the batch.
