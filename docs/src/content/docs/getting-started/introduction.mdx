## What is Gowa-UI?

Gowa-UI is a modern WhatsApp Business Platform built with Go (Fastglue) and Vue.js (shadcn-vue). It provides a comprehensive solution for businesses to manage their WhatsApp communications, automate responses, and engage with customers at scale.

## Tech Stack

### Backend
- **Go 1.21+** with [Fastglue](https://github.com/zerodha/fastglue) (fasthttp-based HTTP framework)
- **PostgreSQL** for data storage with GORM v2
- **Redis** for caching and pub/sub
- **JWT** for authentication

### Frontend
- **Vue 3** with Composition API and TypeScript
- **Vite** for build tooling
- **shadcn-vue** / Radix Vue for UI components
- **TailwindCSS** for styling
- **Pinia** for state management
- **Vue Query** for server state
