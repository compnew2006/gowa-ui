# <div dir="rtl">مرحباً بك في وثائق واتوميت</div>

**واتوميت** هو منصة شاملة لواجهة برمجة تطبيقات واتساب للأعمال تُمكّن المؤسسات من إدارة اتصالات العملاء على نطاق واسع. يدعم بنيتين مزدوجتين للمزودين — واجهة ميتا السحابية المباشرة وواتساب ويب المباشر (WhatsMeow) — مع ميزات قوية للمراسلة والحملات وأتمتة روبوت الدردشة والتعاون الفريقي.

## الميزات الرئيسية

| الميزة | الوصف |
|---------|-------------|
| مزود مزدوج | واجهة ميتا السحابية أو واتساب ويب المباشر (WhatsMeow) |
| متعدد المستأجرين | عزل قائم على المؤسسات مع RBAC |
| الحملات | مراسلة جماعية مع جدولة وتحليلات |
| روبوت الدردشة | قواعد الكلمات المفتاحية وتكامل الذكاء الاصطناعي وتدفقات المحادثة |
| فوري | تحديثات مباشرة مبنية على WebSocket وإشعارات |
| الأمان | مصادقة JWT وحماية CSRF وتشفير أثناء التخزين |
| التحليلات | لوحة قياس ومقاييس الوكلاء وأدوات مخصصة |
| قابل للتوسعة | ويب هوك صادر وإجراءات مخصصة |
