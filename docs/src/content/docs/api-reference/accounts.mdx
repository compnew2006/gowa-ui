## Overview

Accounts represent your WhatsApp device connections managed through GOWA (WhatsApp Web protocol).

## List Accounts

Retrieve all connected WhatsApp accounts.

```bash
GET /api/accounts
```

### Response

```json
{
  "status": "success",
  "data": {
    "items": [
      {
        "id": "uuid",
        "name": "Main Business",
        "phone_number": "+1234567890",
        "status": "active",
        "created_at": "2024-01-01T00:00:00Z"
      }
    ]
  }
}
```

## Get Account

Retrieve a single account.

```bash
GET /api/accounts/{id}
```

### Response

```json
{
  "status": "success",
  "data": {
    "id": "uuid",
    "name": "Main Business",
        "phone_number": "+1234567890",
    "status": "active",
    "quality_rating": "GREEN",
    "messaging_limit": "TIER_1K",
    "created_at": "2024-01-01T00:00:00Z"
  }
}
```

## Create Account

Connect a new WhatsApp account via QR code pairing (GOWA).

```bash
POST /api/accounts
```

### Request Body

```json
{
  "name": "Support Line"
}
```

### Response

```json
{
  "status": "success",
  "data": {
    "id": "uuid",
    "name": "Support Line",
    "status": "pending",
    "created_at": "2024-01-01T00:00:00Z"
  }
}
```

## Update Account

Update account settings.

```bash
PUT /api/accounts/{id}
```

### Request Body

```json
{
  "name": "Customer Support"
}
```

## Delete Account

Remove a WhatsApp account connection.

```bash
DELETE /api/accounts/{id}
```

<Aside type="caution">
  Deleting an account will remove all associated contacts, messages, and settings.
</Aside>

## Test Connection

Verify the account connection.

```bash
POST /api/accounts/{id}/test
```

### Response

```json
{
  "status": "success",
  "data": {
    "connected": true,
    "phone_number": "+1234567890"
  }
}
```

## Account Status

| Status | Description |
|--------|-------------|
| `pending` | Account created, awaiting QR pairing |
| `active` | Account is connected and working |
| `disconnected` | Connection lost, needs reconnection |
