Whatomate User Click & Navigation Guide

User-facing map: what each menu means, where to click, what page opens, and how to complete common tasks.

Quick Orientation

  1. Use the left sidebar to move between modules.
  2. Click a contact to open chat details page /chat/:contactId.
  3. Use Transfers to claim queue chats, assign to agents, or resume bot handling.
  4. Use Chatbot pages to manage keyword rules, flows, and AI contexts.
  5. If you click a page you are not allowed to read, app redirects to your first allowed page.

How To: Common User Tasks

1) Open and reply to a chat

Go to Chat in left sidebar.
Click any contact in the left contacts list.
Conversation opens at /chat/:contactId.
Type message and send.

2) Transfer a chat to agents (pause bot)

Open contact conversation in Chat.
Click transfer icon (UserX) in header.
System creates transfer and marks chat as paused from chatbot.

3) Claim next queue chat

Go to Transfers.
Click Pick Next.
System assigns next queue item and navigates to that chat page.

4) Reassign transfer to team or agent

On Transfers, click Assign on the row.
Choose team queue and/or agent in dialog.
Click Save to apply assignment.

5) Resume chatbot for a transferred chat

From Chat or Transfers, click resume (Play).
Transfer is resumed/closed and chatbot can continue automation for that contact.

Visibility Rules (Why pages/buttons may be missing)

  • Permission rules: Menu entries are shown only when user has required read permission.
  • Meta-only modules: /templates, /flows, /campaigns, /analytics/meta-insights, and /settings/accounts can be hidden when provider feature is off.
  • Route guard: If user opens a blocked route directly, app redirects to first accessible route.
  • Mobile: User must tap menu icon first to show sidebar and then click target menu.
If a user says "I cannot see this page", first check role permissions, then provider mode/features.
