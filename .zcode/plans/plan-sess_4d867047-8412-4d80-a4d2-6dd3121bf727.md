## Fix 5 Bugs from QA Audit

### Bug 1: Campaign recipients not visible after adding (🔴 Medium)
**Root cause:** `<Collapsible :default-open="recipients.length > 0 && recipients.length <= 20">` — `default-open` is uncontrolled (only read once at mount). Page loads with 0 recipients → collapsible starts closed. After adding, data updates but collapsible stays closed.

**File:** `frontend/src/views/settings/CampaignDetailView.vue`
- Add `const recipientsOpen = ref(true)` near line 190 (recipients state section)
- Change `<Collapsible :default-open="...">` at line 1359 → `<Collapsible v-model:open="recipientsOpen">`

---

### Bug 2: "Add Tag" button visible to read-only agent (🟡 Low)
**Root cause:** `TagsView.vue` does not import `useAuthStore` and has no `v-if` guards on any buttons.

**File:** `frontend/src/views/settings/TagsView.vue`
- Add import: `import { useAuthStore } from '@/stores/auth'`
- Add: `const authStore = useAuthStore()`
- Add computed: `const canWriteTags = computed(() => authStore.hasPermission('tags', 'write'))` and `const canDeleteTags = computed(() => authStore.hasPermission('tags', 'delete'))`
- Wrap PageHeader `#actions` slot (line 129): `<template v-if="canWriteTags" #actions>`
- Wrap `#empty-action` slot (line 191): `<template v-if="canWriteTags" #empty-action>`
- Guard Edit button (line 185): add `v-if="canWriteTags"`
- Guard Delete button (line 186): add `v-if="canDeleteTags"`

### Bug 5: Agent chat defaults to empty "Me" tab (🟢 Trivial)
**Root cause:** The `loadStoredTab()` function defaults agents to `'me'`. Code already has a post-auth correction watcher, but agents without `contacts:write` are explicitly set to `'me'`. The logic should default agents to `'pending'` instead.

**File:** `frontend/src/stores/contacts.ts`
- Change the default in `loadStoredTab()` (line ~152) and the post-auth correction watcher (line ~194): when user is NOT a manager (no `contacts:write`), default to `'pending'` instead of `'me'`
