# <div dir="rtl">المصادقة وإعدادات المستخدم</div>

يغطي هذا القسم تسجيل الدخول والتسجيل وإدارة حسابك وتخصيص تجربة واتوميت.

## تسجيل الدخول

**نقطة النهاية:** `POST /api/auth/login`

لتسجيل الدخول، قدّم بريدك الإلكتروني وكلمة المرور:

```json
{
  "email": "you@example.com",
  "password": "your-password"
}
```

**ما يحدث:**

1. يتم التحقق من بيانات اعتمادك بشكل آمن
2. يتم إنشاء رمز وصول (ينتهي بعد 15 دقيقة) ورمز تحديث (ينتهي بعد 7 أيام)
3. يتم تخزين الرموز كملفات تعريف ارتباط آمنة وHTTP-only
4. يتم تحميل ملفك الشخصي وصلاحيات دورك

**الاستجابة:**

```json
{
  "expires_in": 900,
  "user": {
    "id": "uuid",
    "email": "you@example.com",
    "full_name": "Your Name",
    "role": "admin",
    "is_active": true
  }
}
```

> **ملاحظة أمان:** تستخدم محاولات تسجيل الدخول الفاشلة مقارنة bcrypt وهمية لمنع هجمات التوقيت. رسائل الخطأ عامة لتجنب الكشف عما إذا كان البريد الإلكتروني موجوداً.

## التسجيل

**نقطة النهاية:** `POST /api/auth/register`

يتطلب التسجيل رمز دعوة صالح من مدير مؤسستك:

```json
{
  "email": "newuser@example.com",
  "password": "SecurePass123!",
  "full_name": "New User",
  "invitation_token": "jwt-token-from-invite"
}
```

**المتطلبات:**

- رمز دعوة صالح وغير منتهي الصلاحية
- يجب أن تستوفي كلمة المرور سياسة القوة (انظر [سياسة كلمة المرور](#سياسة-كلمة-المرور))
- إذا كان البريد الإلكتروني موجوداً بالفعل، تنجح العملية بصمت دون إنشاء مكرر

## رمز التحديث

**نقطة النهاية:** `POST /api/auth/refresh`

تنتهي رموز الوصول بعد 15 دقيقة. يقوم تدفق رمز التحديث تلقائياً بإنشاء زوج رموز جديد:

1. يتحقق النظام من أن رمز التحديث لم يُستخدم من قبل (منع هجمات الإعادة)
2. يتم إصدار زوج رمز وصول ورمز تحديث جديد
3. يتم الحفاظ على سياق مؤسستك وصلاحياتك

يحدث هذا تلقائياً في الخلفية — لا تحتاج إلى تشغيله يدوياً.

## تسجيل الخروج

**نقطة النهاية:** `POST /api/auth/logout`

يسجل الخروج رمز التحديث الخاص بك ويمسح جميع ملفات تعريف ارتباط المصادقة. يتم إنهاء جميع الجلسات النشطة.

## تبديل المؤسسات

**نقطة النهاية:** `POST /api/auth/switch-org`

إذا كنت تنتمي إلى مؤسسات متعددة، يمكنك التبديل بينها:

```json
{
  "organization_id": "org-uuid"
}
```

يتم إعادة إنشاء كلا الرموزين مع سياق المؤسسة الجديد. يتم تطبيق دورك في المؤسسة المستهدفة تلقائياً.

## المصادقة الموحدة (SSO)

يدعم واتوميت تسجيل الدخول الموحد عبر مزودي OAuth2.

### المزودون المتاحون

**نقطة النهاية:** `GET /api/auth/sso/providers`

تعرض قائمة مزودي SSO المفعّلين لمؤسستك.

### بدء المصادقة الموحدة

**نقطة النهاية:** `GET /api/auth/sso/{provider}/init`

يتم إعادة توجيهك إلى مزود الهوية (مثل Google أو Microsoft) للمصادقة.

### رد نداء المصادقة الموحدة

**نقطة النهاية:** `GET /api/auth/sso/{provider}/callback`

بعد المصادقة، يقوم واتوميت بـ:

1. التحقق من رمز حالة OAuth2 (حماية CSRF)
2. تبادل رمز التفويض للحصول على معلومات المستخدم
3. البحث عن حسابك المحلي أو إنشاؤه
4. إنشاء رموز الجلسة وإعادة توجيهك إلى التطبيق

## سياسة كلمة المرور

يجب أن تستوفي جميع كلمات المرور هذه المتطلبات:

| القاعدة | المتطلب |
|------|------------|
| الحد الأدنى للطول | 8 أحرف |
| أحرف كبيرة | حرف كبير واحد على الأقل |
| أحرف صغيرة | حرف صغير واحد على الأقل |
| رقم | رقم واحد على الأقل |
| حرف خاص | حرف خاص واحد على الأقل |
| كلمات المرور الشائعة | يجب ألا تكون في قائمة الكلمات الشائعة |

### تغيير كلمة المرور

**نقطة النهاية:** `PUT /api/me/password`

```json
{
  "current_password": "old-password",
  "new_password": "NewSecurePass456!"
}
```

بعد تغيير كلمة المرور، يتم إبطال جميع الجلسات الحالية ويجب عليك تسجيل الدخول مرة أخرى.

## إعدادات المستخدم

**نقطة النهاية:** `PUT /api/me/settings`

خصّص تجربتك:

```json
{
  "email_notifications": true,
  "new_message_alerts": true,
  "campaign_updates": true,
  "notification_sound": "notification1",
  "chat_background": "aurora-veil"
}
```

### أصوات الإشعارات

اختر من ثلاثة أصوات مدمجة:

- `notification1`
- `notification2`
- `notification`

### خلفية الدردشة

خصّص خلفية نافذة الدردشة بإعداد مسبق أو ارفع صورتك الخاصة.

**الإعدادات المسبقة المتاحة:**

| الإعداد المسبق | الوصف |
|--------|-------------|
| `aurora-veil` | تدرج شفق ناعم |
| `sunset-dunes` | نغمات صحراوية دافئة |
| `paper-garden` | نقش نباتي خفيف |
| `linen-grid` | شبكة خفيفة على الكتان |
| `dot-orbit` | نقش نقطي مداري |
| `ripple-lines` | خطوط تموج متحدة المركز |

### رفع خلفية مخصصة

**نقطة النهاية:** `POST /api/me/chat-background`

ارفع صورتك الخاصة:

- **الصيغ المسموحة:** JPEG, PNG, WebP
- **الحجم الأقصى:** 5 ميغابايت

### الحصول على الخلفية الحالية

**نقطة النهاية:** `GET /api/me/chat-background`

تعرض إعدادات خلفية الدردشة النشطة حالياً.

## التوافر

**نقطة النهاية:** `PUT /api/me/availability`

تبديل حالة توافرك:

```json
{
  "is_available": true
}
```

عند التعيين إلى `false`، لن تتلقى تعيينات دردشة جديدة. يمكن لفريقك رؤية حالة توافرك في الوقت الفعلي عبر تحديثات WebSocket.

## مصادقة WebSocket

**نقطة النهاية:** `GET /api/auth/ws-token`

ينشئ رمز JWT قصير العمر (30 ثانية) لاتصالات WebSocket. هذا الرمز للاستخدام مرة واحدة ومخصص حصرياً للاتصال الفوري.
