## البداية السريعة

1. **التثبيت** — البناء من المصدر أو استخدام Docker
2. **الإعداد** — إنشاء `config.toml` بإعدادات قاعدة البيانات وRedis
3. **الترحيل** — تشغيل `whatomate -migrate` لإعداد قاعدة البيانات
4. **التشغيل** — تشغيل `whatomate serve` لبدء الخادم
5. **تسجيل الدخول** — استخدام بيانات المدير الافتراضية من الإعدادات

## نظرة عامة على البنية

Whatomate هو تطبيق بملف تنفيذي واحد يدمج:

- **خادم Go HTTP** (fasthttp) — REST API وWebSocket
- **الواجهة الأمامية المدمجة** (React/Vite) — SPA يتم تقديمها من الملف التنفيذي
- **قاعدة بيانات PostgreSQL** — المتجر الرئيسي للبيانات
- **Redis** — التخزين المؤقت، الطابور، النشر/الاشتراك، إدارة الجلسات
- **مزودو WhatsApp** — Meta Cloud API أو WhatsMeow (WhatsApp Web مباشر)

## المفاهيم التشغيلية الرئيسية

- **متعدد المستأجرين**: تتشارك عدة مؤسسات في نسخة واحدة
- **قائم على المزود**: اختر Meta Cloud API أو WhatsMeow لكل نشر
- **الحذف الناعم**: جميع عمليات الحذف ناعمة (تحافظ على البيانات مع `deleted_at`)
- **أسرار مشفرة**: تستخدم الحقول الحساسة تشفير AES-256-GCM
- **العمال في الخلفية**: معالجة SLA، تسليم الحملات، الاحتفاظ بالنشاط تعمل كـ goroutines
