## عام

### ما هو واتوميت؟

واتوميت هو منصة واتساب للأعمال ذاتية الاستضافة ومتعددة المستأجرين. تُمكّن المؤسسات من إدارة اتصالات العملاء على نطاق واسع من خلال الرسائل والحملات وأتمتة روبوت الدردشة والتعاون بين الفرق.

### ما هي المزودات المدعومة؟

يدعم واتوميت مزودين للواتساب:

- **Meta Cloud API** — واجهة واتساب للأعمال السحابية الرسمية من Meta مع اعتماد القوالب وFlows والكتالوجات
- **WhatsMeow** — اتصال مباشر عبر بروتوكول واتساب ويب باستخدام `go.mau.fi/whatsmeow`، بدون حاجة لاعتماد القوالب

تختار المزود في ملف `config.toml` تحت `whatsapp.provider`.

### ما الفرق بين Meta وWhatsMeow؟

| الميزة | Meta Cloud API | WhatsMeow |
|---------|---------------|-----------|
| الاتصال | واجهة رسمية عبر HTTP | بروتوكول واتساب ويب مباشر |
| المصادقة | رموز وصول | رمز QR أو اقتران برمز الهاتف |
| القوالب | تتطلب اعتماد Meta | بدون حاجة للاعتماد |
| Flows/الكتالوجات | مدعومة | غير متاحة |
| حدود المعدل | مفروضة من Meta | قابلة للتكوين لكل نسخة |
| الموثوقية | عالية (رسمية) | تعتمد على استقرار واتساب ويب |

### هل يمكنني استخدام كلا المزودين في نفس الوقت؟

لا. يتم تكوين المزود بشكل عام في `config.toml`. يمكنك التبديل بينهما، لكن واحد فقط يكون نشطًا في كل مرة.

## المصادقة والمستخدمون

### كيف تعمل المصادقة؟

يستخدم واتوميت JWT (HS256) بنظام رمزين:

1. **رمز الوصول** — قصير العمر (15 دقيقة)، يُستخدم لطلبات API
2. **رمز التحديث** — طويل العمر (7 أيام)، يُستخدم لإنشاء رموز وصول جديدة

يتم تخزين كلا الرمزين في ملفات تعريف ارتباط HTTP-only وSecure وSameSite=Strict. يستخدم رمز التحديث التدوير أحادي الاستخدام لمنع هجمات الإعادة.

### هل يمكنني استخدام SSO؟

نعم. يدعم واتوميت تسجيل الدخول الموحد القائم على OAuth2. قم بتكوين مزودي SSO في إعدادات المسؤول أو عبر API في `/api/settings/sso`.

### كيف أدعو أعضاء الفريق؟

يمكن للمسؤولين دعوة المستخدمين عبر تدفق التسجيل. يتم إنشاء رمز دعوة (JWT) ومشاركته مع المستخدم الجديد، الذي يستخدمه أثناء التسجيل في `POST /api/auth/register`.

## الرسائل والحملات

### كيف تعمل الحملات؟

ترسل الحملات رسائل قالبية إلى قائمة من المستلمين:

1. أنشئ حملة بقالب وإعدادات
2. استورد المستلمين عبر CSV/JSON
3. ابدأ الحملة — يتم نشر المستلمين إلى قائمة انتظار Redis
4. تعالج العمليات الخلفية المهام بتأخيرات عشوائية
5. يتم تتبع التقدم وبثه عبر WebSocket في الوقت الفعلي

### هل يمكنني جدولة الحملات؟

نعم. عيّن الحقل `scheduled_at` عند إنشاء حملة. ستبدأ الحملة تلقائيًا في الوقت المحدد.

### كيف يتم التعامل مع تأخيرات الرسائل؟

كل حملة تحتوي على `min_delay_seconds` و`max_delay_seconds` قابلة للتكوين (الافتراضي: 20-45 ثانية). يتم اختيار التأخير الفعلي لكل رسالة عشوائيًا ضمن هذا النطاق لإنشاء أنماط إرسال تبدو طبيعية.

### هل يمكنني إعادة محاولة الرسائل الفاشلة في الحملة؟

نعم. استخدم `POST /api/campaigns/{id}/retry-failed` لإعادة محاولة الإرسال إلى جميع المستلمين الذين فشلوا سابقًا.

## روبوت الدردشة

### كيف أعدّد روبوت الدردشة؟

1. انتقل إلى إعدادات روبوت الدردشة (`GET /api/chatbot/settings`)
2. فعّل روبوت الدردشة وقم بتكوين:
   - رسالة الترحيب
   - رسالة الاحتياط
   - ساعات العمل
   - مهلة الجلسة
3. أضف قواعد الكلمات المفتاحية للردود التلقائية
4. فعّل تكامل الذكاء الاصطناعي اختياريًا باستخدام مفتاح API

### هل يدعم روبوت الدردشة الذكاء الاصطناعي؟

نعم. يدعم واتوميت الردود المدعومة بالذكاء الاصطناعي عبر مزودين خارجيين مثل OpenAI. قم بتكوين مزود الذكاء الاصطناعي والنموذج ومفتاح API وموجه النظام في إعدادات روبوت الدردشة. يتم تشفير مفتاح API الخاص بالذكاء الاصطناعي قبل التخزين.

### ماذا يحدث خارج ساعات العمل؟

عندما تكون خارج ساعات العمل المُكوّنة، يمكنك اختيار:
- تعطيل الأتمتة ووضع الرسائل في قائمة انتظار للوكلاء
- إرسال رسالة مخصصة خارج ساعات العمل
- متابعة الأتمتة كالمعتاد

### هل يمكن لروبوت الدردشة نقل المحادثة إلى وكيل بشري؟

نعم. يمكن لتدفقات روبوت الدردشة وقواعد الكلمات المفتاحية تفعيل نقل الوكيل. يتم وضع عمليات النقل في قائمة انتظار ويتم إشعار الوكلاء المتاحين عبر WebSocket.

## الأمان

### كيف يتم تشفير الرسائل؟

يستخدم واتوميت تشفير AES-256-GCM للبيانات الحساسة المخزنة في قاعدة البيانات، بما في ذلك:

- رموز وصول حسابات واتساب
- رموز التحقق من Webhook
- أسرار عملاء SSO
- مفاتيح API لذكاء اصطناعي روبوت الدردشة
- أسرار Webhook

يتم تكوين مفتاح التشفير في `config.toml` تحت `app.encryption_key`.

### كيف أدور مفتاح التشفير؟

1. أنشئ مفتاح تشفير جديد بحجم 32 بايت
2. حدّث `config.toml` أو عيّن `WHATOMATE_APP_ENCRYPTION_KEY`
3. شغّل `whatomate crypto-migrate` لإعادة تشفير جميع البيانات الموجودة

### هل يمكنني تقييد من يمكنه إرسال الرسائل؟

نعم. يحتوي واتوميت على نظام شامل لتقييد الإرسال:

- **على مستوى المؤسسة:** تفعيل الوضع الصارم، تعيين وضع الصادر (inbound_only/mixed)، فرض مسودة الحملة فقط
- **على مستوى المستخدم:** تقييد أرقام الهواتف المصرح بها، النسخ المسموحة، الوصول إلى الدردشات غير المطالب بها
- **أوضاع التنفيذ:** Audit (تسجيل الانتهاكات) أو Enforce (حظر الرسائل)

### ما هي حماية CSRF المستخدمة؟

يستخدم واتوميت نمط ملف تعريف ارتباط double-submit. يتم تخزين رمز CSRF في ملف تعريف ارتباط HTTP-only (`whm_csrf`) ويجب إرساله في رأس `X-CSRF-Token` لجميع الطلبات المعدّلة (POST, PUT, DELETE, PATCH).

## Webhooks

### كيف تعمل Webhooks؟

يدعم واتوميت Webhooks صادرة تُبلغ الأنظمة الخارجية بالأحداث:

1. أنشئ webhook بعنوان URL واشتراكات الأحداث
2. عند وقوع حدث (إرسال رسالة، إنشاء جهة اتصال، إلخ)، يرسل واتوميت طلب POST إلى عنوان URL الخاص بك
3. يتم توقيع الحمولات بـ HMAC-SHA256 إذا تم تكوين سر
4. يتم تسجيل محاولات التسليم

### ما الأحداث التي يمكنني الاشتراك فيها؟

تشمل الأحداث الشائعة: `message.received` و`message.sent` و`message.status_updated` و`contact.created` و`contact.assigned` و`chat.closed` و`campaign.stats_update` وغيرها.

### كيف أتحقق من توقيعات Webhook؟

إذا قمت بتكوين سر webhook، فتحقق من رأس `X-Webhook-Signature-256` باستخدام HMAC-SHA256 مع السر الخاص بك.

## المراقبة والعمليات

### كيف أراقب صحة النظام؟

يوفر واتوميت نقطتي نهاية:

- **`GET /health`** — فحص صحة أساسي، يُرجع `{"status": "ok"}`
- **`GET /ready`** — فحص الجاهزية، يتحقق من اتصال قاعدة البيانات وRedis

استخدم هذه لفحوصات صحة موازن الحمل أو مسابر Kubernetes.

### كيف أنسخ بياناتي احتياطيًا؟

انسخ هذه المكونات احتياطيًا:

1. **قاعدة بيانات PostgreSQL** — استخدم `pg_dump` أو أداة النسخ الاحتياطي لمزود قاعدة البيانات
2. **Redis** — استخدم `redis-cli BGSAVE` أو فعّل استمرار RDB/AOF
3. **ملفات الوسائط** — انسخ دليل التخزين المُكوّن في `storage.local_path`
4. **التكوين** — احتفظ بنسخة من `config.toml` ومتغيرات البيئة

### كيف أستعيد من النسخة الاحتياطية؟

1. استعد قاعدة بيانات PostgreSQL: `psql -d whatomate < backup.sql`
2. استعد بيانات Redis من ملفات RDB/AOF
3. استعد ملفات الوسائط إلى دليل التخزين
4. أعد تشغيل خادم واتوميت

## التطوير

### كيف أساهم في واتوميت؟

راجع [دليل المساهمة](developers/contributing.md) لمعرفة نمط الكود وعملية PR وكيفية إضافة ميزات جديدة.

### كيف أشغّل الاختبارات؟

```bash
# تشغيل جميع الاختبارات
go test ./...

# تشغيل مع التغطية
go test -coverprofile=coverage.out ./...

# تشغيل اختبارات E2E
cd frontend && npm run test:e2e
```

### ما هو عنوان URL الأساسي لـ API؟

جميع نقاط نهاية API مسبوقة بـ `/api`. على سبيل المثال: `http://localhost:8080/api/auth/login`.
