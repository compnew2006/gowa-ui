### 🔴 Q3b (الأولوية الأولى — الأسهل والأعلى تأثير): فلتر المحادثات الفارغة

**المشكلة:** جهات اتصال GOWA المُزامنة (بدون رسائل) بتظهر في `/chat` كأنها محادثات.

**السبب الجذري (مؤكد بالكود):** في `internal/handlers/contacts.go` ListContacts بترجع كل الـ contacts من غير فلتر على وجود رسائل. الـ ordering (`contacts.go` السطر ~80) بيستخدم `last_message_at DESC NULLS LAST` — يعني بيأخّر الفاضية بس مش بيخفيها.

**الحل (أفضل ممارسة):** فلتر اختياري `has_messages` في الـ API، يستخدمه ChatView افتراضيًا.

**التعديلات:**
1. `internal/handlers/contacts.go` (ListContacts): ضِف query param اختياري
   ```go
   hasMessages := string(r.RequestCtx.QueryArgs().Peek("has_messages"))
   if hasMessages == "true" {
       query = query.Where("last_message_at IS NOT NULL")
   }
   ```
2. `frontend/src/stores/contacts.ts:344` (fetchContacts): ضِف param افتراضي للـ chat
   ```ts
   async function fetchContacts(params?: { search?, page?, limit?, tags?, has_messages? })
   ```
3. `frontend/src/views/chat/ChatView.vue`: استدعاء fetchContacts بـ `has_messages: true` افتراضيًا.
4. `/settings/contacts` (ContactsView): يفضل زي ما هو (بدون الفلتر — يعرض الكل كـ directory).

**النتيجة:** `/chat` بتعمل display بس للمحادثات الحقيقية. `/settings/contacts` يفضل directory كامل.

### 🟡 Q3a: ختم الحساب الدائم في GOWA sync

**المشكلة:** جهات الاتصال المُزامنة مش بيبان منها أي حساب جاية.

**السبب (مؤكد بالكود):** `internal/handlers/gowa_instances.go:661` بيشترط `if contact.WhatsAppAccount == ""` قبل ما يكتب الحساب. لو الحقل سبق اتعمّل بـ empty string أو قيمة غلط، مش بيتح.update.

**الحل:** شيل الشرط وخلي الـ sync دايمًا يكتب الحساب الصحيح (sync من server معين = حساب معين). التعديل في مكانين:
1. `internal/handlers/gowa_instances.go:661` (sync-contacts)
2. `internal/handlers/gowa_instances.go:808` (sync-messages) — نفس النمط

```go
// قبل
if contact.WhatsAppAccount == "" {
    a.DB.Model(contact).Update("whats_app_account", account.Name)
}
// بعد — دائمًا ختم بالحساب المُزامَن منه
a.DB.Model(contact).Update("whats_app_account", account.Name)
```

**النتيجة:** كل جهة اتصال جاية من GOWA server معيّن هتتحط على حسابها الصح، و الـ Contacts UI filter هيشتغل.

### 🟢 Q2: قائمة "Closed/Archived" للمحادثات المقفولة

**المشكلة:** بعد `CloseChat`، المحادثة بتختفي من نظر غير الـ owner.

**السبب (مؤكد):** `chat_status` بيتخزن جوّه `Metadata["chat_status"]` كـ `"closed"`. الفلاتر الحالية: Pending بيستثني `closed`، Me بيشوف بس `assigned_user_id === user.id`. يعني لو مينش الـ owner → مش بيشوفها في أي تبويب.

**الحل (أفضل ممارسة):** إضافة تبويب تالت **"Closed"** مرئي لكل من له صلاحية `contacts.read` (نفس الـ gate الموجود في `scopeAssignedContact`).

**التعديلات:**
1. `frontend/src/stores/contacts.ts:126` (VALID_TABS): ضِف `'closed'`
   ```ts
   const VALID_TABS = ['me', 'pending', 'closed'] as const
   ```
2. `frontend/src/stores/contacts.ts:215` (الفلاتر): ضِف computed جديد
   ```ts
   const closedContacts = computed(() =>
     sortedContacts.value.filter(c => c.chat_status === 'closed')
   )
   ```
3. `frontend/src/stores/contacts.ts:225` (displayedContacts): ضِف case
   ```ts
   case 'closed': return closedContacts.value
   ```
4. `frontend/src/views/chat/ChatView.vue` (الـ template عند السطر ~2189): ضِف تبويب Closed مرئي للـ managers/admins (زي ما Pending بيظهر للـ managers بس).

**النتيجة:** المحادثات المقفولة مرئية، مرتبة، وممكن تتعاد فتحها (Reopen موجود بالفعل في الكود).

### 🔵 Q1: تبويب "All" للأدمن (رؤية شاملة)

**المشكلة:** لما حد يعمل Claim، المحادثة بتختفي من نظر الأدمن.

**السبب (مؤكد):** الـ backend فعلاً بيسمح للأدمن (اللي معاه `contacts:read`) يشوف كل المحادثات عبر `scopeAssignedContact` — الفجوة في الـ frontend مفيهاش تبويب بيستغل ده.

**الحل:** ضِف تبويب **"All"** للأدمن بس (زي ما Pending بيظهر للـ managers). ده بسيط لأن الـ backend جاهز.

**التعديلات:**
1. `frontend/src/stores/contacts.ts`: ضِف `'all'` لـ VALID_TABS + computed
   ```ts
   const allContacts = computed(() => sortedContacts.value) // بدون فلتر
   ```
   + case في displayedContacts.
2. `frontend/src/views/chat/ChatView.vue`: ضِف التبويب، مرئي بس لو `authStore.hasPermission('contacts', 'read')` أو isManager.

**النتيجة:** الأدمن يقدر يشوف كل المحادثات (مسندة أو لأ، مفتوحة أو مقفولة) في تبويب واحد، ولو حابب يشوف محادثة بين موظف وعميل بيبقى متاح له.
