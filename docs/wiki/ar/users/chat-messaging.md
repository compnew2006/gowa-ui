# <div dir="rtl">الدردشة والمراسلة</div>

أرسل واستقبل رسائل واتساب، وأدِر دورات حياة الدردشة، واستخدم ميزات المراسلة الغنية مثل التفاعلات وقراءات الاستلام ومعاينات الرد.

## عرض الدردشات

تُعرض الدردشات في قائمة جهات الاتصال مع تحديثات فورية. تُظهر كل دردشة:

- اسم جهة الاتصال ورقم الهاتف
- معاينة آخر رسالة والطابع الزمني
- عدد الرسائل غير المقروءة
- الوكيل المعيّن (إن وجد)
- العلامات ومؤشرات الحالة

### حالات الدردشة

| الحالة | الوصف |
|-------|-------------|
| **مفتوحة** | محادثة نشطة، يمكن إرسال واستقبال الرسائل |
| **مغلقة** | انتهت المحادثة، وضع القراءة فقط حتى إعادة الفتح |
| **قيد الانتظار** | بانتظار تعيين وكيل |

## الرسائل

### عرض الرسائل

**نقطة النهاية:** `GET /api/chats/{id}/messages`

يتم تحميل الرسائل مع ترقيم صفحات قائم على المؤشر للتمرير السلس:

```
GET /api/chats/{id}/messages?limit=50&before=cursor-token
```

**الميزات:**

- يتم تجميع الرسائل حسب التاريخ
- يتم التمييز بصرياً بين الرسائل الواردة والصادرة
- يتم عرض سياق الرد inline عندما تشير رسالة إلى أخرى
- تعرض رسائل الوسائط صوراً مصغرة مع روابط تنزيل
- تظهر رسائل النظام (مثل "أغلقت الدردشة بواسطة الوكيل") كإشعارات inline

### أنواع الرسائل

| النوع | الوصف |
|------|-------------|
| نص | رسائل نصية عادية |
| وسائط | صور وفيديوهات وصوت ومستندات |
| قالب | رسائل قالب واتساب المعتمدة مسبقاً |
| تفاعلية | رسائل بأزرار أو قوائم أو رابط CTA |
| تفاعل | رموز تعبيرية كتفاعل على رسائل موجودة |
| نظام | أحداث دورة حياة داخلية |

## إرسال الرسائل

### رسالة نصية

**نقطة النهاية:** `POST /api/contacts/{id}/messages`

```json
{
  "content": "مرحباً! كيف يمكنني مساعدتك اليوم؟",
  "reply_to_message_id": "msg-uuid"
}
```

يؤدي تضمين `reply_to_message_id` إلى إنشاء رد مترابط مع معاينة للرسالة الأصلية.

### رسالة وسائط

**نقطة النهاية:** `POST /api/messages/media`

ارفع وأرسل وسائط في خطوة واحدة:

- **الأنواع المدعومة:** صورة، فيديو، صوت، مستند
- **العملية:** يتم رفع الملف إلى التخزين ثم إرساله عبر واتساب
- **التسمية التوضيحية:** نص اختياري يرافق الوسائط

### رسالة قالب

**نقطة النهاية:** `POST /api/messages/template`

```json
{
  "template_id": "template-uuid",
  "contact_id": "contact-uuid",
  "parameters": {
    "1": "أحمد",
    "2": "طلبك رقم #12345"
  }
}
```

تستخدم رسائل القوالب قوالب ميتا المعتمدة مسبقاً مع حل العناصر النائبة ديناميكياً.

### الرسائل التفاعلية

أرسل رسائل تفاعلية غنية بأزرار أو قوائم:

| النوع | الوصف | الحد |
|------|-------------|-------|
| **زر** | أزرار رد سريع | حتى 3 أزرار |
| **قائمة** | قائمة اختيار واحد مع أقسام | حتى 10 خيارات |
| **رابط CTA** | زر دعوة للعمل مع رابط | زر واحد |

```json
{
  "interactive": {
    "type": "button",
    "header": "اختر خياراً",
    "body": "كيف تريد المتابعة؟",
    "buttons": [
      { "id": "1", "title": "الدعم" },
      { "id": "2", "title": "المبيعات" }
    ]
  }
}
```

> **ملاحظة:** تتطلب الرسائل التفاعلية مزود ميتا. دعم WhatsMeow محدود.

## دورة حياة الدردشة

### مطالبة دردشة

**نقطة النهاية:** `PUT /api/chats/{id}/claim`

تولّ ملكية دردشة غير معينة أو قيد الانتظار:

1. يتم تعيين الدردشة لك
2. يتم إشعار الوكلاء الآخرين عبر WebSocket
3. يمكنك الآن إرسال الرسائل إلى جهة الاتصال هذه

### إغلاق دردشة

**نقطة النهاية:** `PUT /api/chats/{id}/close`

إنهاء محادثة:

1. تتغير حالة الدردشة إلى `مغلقة`
2. تسجل رسالة النظام من أغلقها ومتى
3. اختيارياً، يتم إرسال طلب تقييم رضا
4. يتم إشعار جميع المشاركين عبر WebSocket

### إعادة فتح دردشة

**نقطة النهاية:** `PUT /api/chats/{id}/reopen`

إعادة فتح محادثة مغلقة:

1. يتم مسح الطابع الزمني `closed_at`
2. تعود الحالة إلى `مفتوحة`
3. تسجل رسالة النظام إعادة الفتح
4. يتم إشعار جميع المشاركين

### تعيين الدردشة كعامة

**نقطة النهاية:** `PUT /api/chats/{id}/public`

تبديل العلم `is_public` للسماح بوصول المتعاونين. الدردشات العامة مرئية لجميع الوكلاء، وليس فقط المستخدم المعيّن.

## التفاعلات

**نقطة النهاية:** `POST /api/contacts/{id}/messages/{message_id}/reaction`

أرسل رموز تعبيرية كتفاعل على أي رسالة:

```json
{
  "emoji": "\uD83D\uDC4D"
}
```

تظهر التفاعلات inline على الرسالة الأصلية في عرض الدردشة.

## إلغاء رسالة

**نقطة النهاية:** `POST /api/contacts/{id}/messages/{message_id}/revoke`

حذف رسالة مرسلة سابقاً للجميع. يتم استبدال الرسالة بإشعار "تم حذف هذه الرسالة".

## قراءات الاستلام

**نقطة النهاية:** `PUT /api/messages/{id}/read`

وضع علامة على الرسائل الواردة كمقروءة. يرسل هذا إشعار قراءة إلى جهة الاتصال عبر واتساب ويحدث حالة الرسالة في النظام.

## مؤشرات الكتابة

**نقطة النهاية:** `POST /api/contacts/{id}/typing`

إظهار أو إخفاء مؤشر "يكتب...":

```json
{
  "state": "composing"
}
```

استخدم `composing` لإظهار الكتابة و`paused` لإخفائها. يتم توجيه المؤشر عبر المزود المُعد (Meta أو WhatsMeow).

## معاينة الرد

عندما تشير رسالة إلى رسالة أخرى، يتم عرض معاينة رد تُظهر:

- محتوى الرسالة الأصلية (مقتطع للرسائل الطويلة)
- مؤشر نوع الرسالة (نص، صورة، إلخ)
- اسم المرسل
- صورة مصغرة للوسائط (إن وجدت)

## نطاق دردشة الوكيل

إذا كان لديك دور **الوكيل**، فإن رؤية الدردشة مقيدة:

| يمكنك رؤية | لا يمكنك رؤية |
|-------------|----------------|
| الدردشات المعينة لك | الدردشات المعينة لوكلاء آخرين |
| الدردشات العامة (`is_public = true`) | الدردشات الخاصة المعينة لآخرين |
| الدردشات التي أنت متعاون فيها | الدردشات غير المعينة (ما لم يُعد ذلك) |

عند إرسال رسالة، يتحقق النظام من أنك تملك صلاحية الوصول إلى جهة الاتصال. إذا كانت الدردشة مغلقة أو غير مطالَبة، ستتلقى رسالة خطأ مناسبة.

## التحديثات الفورية

يتم بث جميع أحداث الدردشة عبر WebSocket في الوقت الفعلي:

| الحدث | الوصف |
|-------|-------------|
| `message` | تم استلام رسالة جديدة |
| `message_status` | تم تحديث حالة تسليم الرسالة |
| `chat_closed` | تم إغلاق الدردشة |
| `chat_reopened` | تم إعادة فتح الدردشة |
| `contact_assigned` | تم تعيين جهة اتصال لمستخدم |
| `typing` | مؤشر الكتابة |
| `presence` | حالة اتصال جهة الاتصال (متصل/غير متصل) |
