<div dir="rtl">الردود الجاهزة</div>

إنشاء وإدارة الردود المكتوبة مسبقاً للردود السريعة أثناء المحادثات. توفر الردود الجاهزة الوقت، وتضمن الاتساق، ويمكن أن تتضمن مرفقات وسائط.

## نظرة عامة

الردود الجاهزة هي قوالب رسائل قابلة لإعادة الاستخدام يمكن للوكلاء إدراجها في المحادثات بنقرة واحدة أو اختصار. يتتبع كل رد عدد الاستخدامات الخاص به حتى تتمكن من تحديد أكثرها فائدة.

## سرد الردود الجاهزة

**Endpoint:** `GET /api/canned-responses`

```
GET /api/canned-responses?category=billing&search=refund
```

| الفلتر | الوصف |
|--------|-------------|
| **Category** | التصفية حسب فئة الرد |
| **Search** | البحث حسب الاختصار أو نص المحتوى |

يتضمن كل رد:

- مفتاح اختصار للكتابة السريعة
- المحتوى (نص الرسالة)
- الفئة للتنظيم
- عدد الاستخدامات (عدد مرات الإرسال)
- مرفق وسائط اختياري

## إنشاء رد جاهز

**Endpoint:** `POST /api/canned-responses`

```json
{
  "shortcut": "refund_policy",
  "content": "تسمح سياسة الاسترداد الخاصة بنا بالإرجاع خلال 30 يوماً من الشراء. يرجى تقديم رقم طلبك وسنقوم بمعالجة استردادك خلال 5-7 أيام عمل.",
  "category": "billing",
  "media_id": null
}
```

| الحقل | مطلوب | الوصف |
|-------|----------|-------------|
| **shortcut** | نعم | اختصار الكتابة السريعة (يجب أن يكون فريداً) |
| **content** | نعم | نص الرسالة المرسل |
| **category** | لا | الفئة التنظيمية |
| **media_id** | لا | معرف مرفق الوسائط الاختياري |

**التحقق:**

- يجب أن تكون الاختصارات فريدة داخل مؤسستك
- لا يمكن أن يكون المحتوى فارغاً
- يجب أن تشير مرفقات الوسائط إلى وسائط صالحة تم تحميلها

## تحديث رد جاهز

**Endpoint:** `PUT /api/canned-responses/{id}`

تعديل أي حقل لرد جاهز موجود:

```json
{
  "content": "نص سياسة الاسترداد المحدّث...",
  "category": "billing-updates"
}
```

## حذف رد جاهز

**Endpoint:** `DELETE /api/canned-responses/{id}`

إزالة رد جاهز بشكل دائم. لا يمكن التراجع عن هذا الإجراء.

## إرسال رد جاهز

**Endpoint:** `POST /api/canned-responses/{id}/send`

إرسال رد جاهز مباشرة إلى جهة اتصال:

```json
{
  "contact_id": "contact-uuid"
}
```

**ما يحدث:**

1. يتم تحميل محتوى الرد الجاهز والوسائط
2. يتم إنشاء رسالة وتوجيهها عبر خط الإرسال القياسي
3. يتم إرسال الرسالة عبر واتساب (Meta أو WhatsMeow)
4. يتم زيادة عدد الاستخدامات تلقائياً

هذا يعادل كتابة المحتوى يدوياً، لكنه أسرع وبتنسيق متسق.

## تتبع الاستخدام

**Endpoint:** `POST /api/canned-responses/{id}/use`

زيادة عداد الاستخدام يدوياً. يتم استدعاؤه تلقائياً عند إرسال رد جاهز، ولكن يمكن أيضاً تشغيله يدوياً لأغراض التتبع.

### إحصائيات الاستخدام

يساعد عدد الاستخدامات في تحديد:

- **الردود الأكثر استخداماً** — الردود الشائعة التي يعتمد عليها الوكلاء
- **الردود غير المستخدمة** — مرشحة للتنظيف أو المراجعة
- **الردود الرائجة** — الردود التي تشهد زيادة في الاستخدام (قد تشير إلى مشكلة شائعة لدى العملاء)

## مرفقات الوسائط

يمكن أن تتضمن الردود الجاهزة ملفات وسائط:

| نوع الوسائط | الوصف |
|------------|-------------|
| **Image** | JPEG, PNG, WebP |
| **Video** | MP4, 3GP |
| **Audio** | OGG, MP3 |
| **Document** | PDF, DOC, DOCX, XLS, XLSX |

### تحميل الوسائط للردود الجاهزة

**Endpoint:** `POST /api/canned-responses/media`

تحميل ملف وسائط واستلام معرف وسائط لإرفاقه برد جاهز:

1. تحميل الملف عبر بيانات نموذج متعددة الأجزاء
2. يتم تخزين الملف والتحقق منه
3. يتم إرجاع معرف وسائط
4. استخدم هذا المعرف في حقل `media_id` عند إنشاء أو تحديث رد جاهز

### تقديم الوسائط المرفقة

عند إرسال رد جاهز يحتوي على وسائط، يتم تقديم الوسائط عبر endpoint الوسائط القياسي:

**Endpoint:** `GET /api/media/{message_id}`

## التنظيم بالفئات

استخدم الفئات لتجميع الردود الجاهزة حسب الموضوع:

| أمثلة على الفئات | حالة الاستخدام |
|--------------------|----------|
| `billing` | سياسات الاسترداد، طرق الدفع، الفواتير |
| `support` | خطوات استكشاف الأخطاء، إجابات الأسئلة الشائعة |
| `sales` | معلومات المنتج، التسعير، العروض الترويجية |
| `greeting` | رسائل الترحيب، عبارات الوداع |
| `escalation` | رسائل النقل إلى مدير |

## أفضل الممارسات

1. **اجعل الاختصارات سهلة التذكر** — استخدم أسماء وصفية مثل `refund_policy` بدلاً من `rp1`
2. **استخدم الفئات بشكل متسق** — أنشئ اصطلاح تسمية فئات لفريقك
3. **راجع الاستخدام بانتظام** — أزل أو حدّث الردود التي لم تعد ذات صلة
4. **تضمين العناصر النائبة** — استخدم عناصر نائبة مثل `{{contact.name}}` للتخصيص
5. **اختبر قبل المشاركة** — أرسل الردود الجاهزة الجديدة لنفسك للتحقق من التنسيق
