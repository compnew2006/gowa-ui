<div dir="rtl">التحليلات</div>

تتبع الأداء عبر جميع ميزات Whatomate مع لوحات معلومات شاملة، وتحليلات الرسائل، ومقاييس روبوت الدردشة، وتقارير أداء الوكلاء، والأدوات المخصصة.

## نظرة عامة على لوحة المعلومات

**Endpoint:** `GET /api/analytics/dashboard`

توفر لوحة المعلومات ملخصاً عالي المستوى لنشاط مؤسستك:

- **إجمالي جهات الاتصال** — عدد جهات الاتصال الفريدة في مؤسستك
- **إجمالي الرسائل** — جميع الرسائل المرسلة والمستلمة
- **المحادثات المفتوحة** — المحادثات النشطة حالياً
- **نشاط اليوم** — الرسائل وجهات الاتصال والمحادثات التي تم إنشاؤها اليوم
- **متوسط وقت الاستجابة** — مدى سرعة استجابة الوكلاء للرسائل

## تحليلات الرسائل

**Endpoint:** `GET /api/analytics/messages`

تفصيل مفصل لنشاط المراسلة عبر نطاق زمني:

```
GET /api/analytics/messages?from=2024-01-01&to=2024-12-31
```

### المقاييس

| المقياس | الوصف |
|--------|-------------|
| **إجمالي المرسل** | الرسائل الصادرة المرسلة |
| **إجمالي المستلم** | الرسائل الواردة المستلمة |
| **معدل التسليم** | نسبة الرسائل التي تم تسليمها بنجاح |
| **معدل القراءة** | نسبة الرسائل التي قرأها المستلمون |
| **معدل الفشل** | نسبة الرسائل التي فشلت في الإرسال |

### التجميع

يتم تجميع الرسائل حسب:

| البعد | الوصف |
|-----------|-------------|
| **Type** | نص، وسائط، قالب، تفاعلي |
| **Direction** | وارد أو صادر |
| **Status** | معلق، مرسل، مُسلَّم، مقروء، فاشل |
| **Date** | بيانات سلاسل زمنية لتحليل الاتجاهات |

### فلتر المثيل

تصفية التحليلات حسب مثيل واتساب محدد لمقارنة الأداء عبر الحسابات.

## تحليلات روبوت الدردشة

**Endpoint:** `GET /api/analytics/chatbot`

قياس فعالية أتمتة روبوت الدردشة الخاص بك:

| المقياس | الوصف |
|--------|-------------|
| **إجمالي الجلسات** | عدد جلسات روبوت الدردشة التي تم إنشاؤها |
| **ردود الذكاء الاصطناعي** | الرسائل التي أنشأها مزود الذكاء الاصطناعي |
| **نقل الوكلاء** | المحادثات المنقولة من روبوت الدردشة إلى وكلاء بشريين |
| **معدل الحل** | نسبة الجلسات التي تم حلها دون نقل إلى وكيل |
| **استخدام الكلمات المفتاحية** | قواعد الكلمات المفتاحية التي تطابقت بشكل متكرر |
| **استخدام التدفقات** | تدفقات المحادثة التي تم تفعيلها أكثر |

### أداء الكلمات المفتاحية

عرض قواعد الكلمات المفتاحية التي يتم تفعيلها بشكل متكرر وفعاليتها في حل الاستفسارات دون تدخل الوكيل.

### أداء التدفقات

تتبع عدد المحادثات التي تكمل كل تدفق مقابل الانقطاع أو الحاجة إلى نقل إلى وكيل.

## تحليلات الوكلاء

**Endpoint:** `GET /api/analytics/agents`

مقاييس الأداء لكل وكيل في مؤسستك:

| المقياس | الوصف |
|--------|-------------|
| **المحادثات المُدارة** | إجمالي المحادثات التي أدارها الوكيل |
| **الرسائل المرسلة** | الرسائل الصادرة التي أرسلها الوكيل |
| **متوسط وقت الاستجابة** | الوقت من الرسالة الواردة إلى رد الوكيل |
| **متوسط وقت الحل** | الوقت من فتح المحادثة إلى إغلاقها |
| **تقييمات العملاء** | تقييمات الرضا المستلمة على المحادثات المغلقة |

### تفاصيل الوكيل

**Endpoint:** `GET /api/analytics/agents/{id}`

عرض مقاييس مفصلة لوكيل محدد، بما في ذلك:

- اتجاهات النشاط اليومية/الأسبوعية/الشهرية
- حجم المحادثات بمرور الوقت
- توزيع وقت الاستجابة
- توزيع وقت الحل

### مقارنة الوكلاء

**Endpoint:** `GET /api/analytics/agents/comparison`

مقارنة عدة وكلاء جنباً إلى جنب:

| الوكيل | المحادثات | متوسط الاستجابة | متوسط الحل | التقييم |
|-------|-------|--------------|----------------|--------|
| Alice | 150 | 2.3 دقيقة | 18 دقيقة | 4.8 |
| Bob | 120 | 3.1 دقيقة | 22 دقيقة | 4.5 |
| Carol | 95 | 1.8 دقيقة | 15 دقيقة | 4.9 |

### تصدير تقييمات الوكلاء

**Endpoint:** `GET /api/analytics/agents/ratings/export`

تنزيل ملف CSV أو JSON لجميع تقييمات رضا العملاء للتحليل الخارجي.

## تحليلات Meta

**Endpoint:** `GET /api/analytics/meta`

> **ملاحظة:** يتطلب مزود Meta (Cloud API).

جلب مقاييس المحادثات والمراسلة مباشرة من واجهة برمجة تحليلات Meta:

| المقياس | الوصف |
|--------|-------------|
| **المحادثات التي بدأت** | نوافذ محادثات جديدة لمدة 24 ساعة |
| **المحادثات المستمرة** | محادثات مستمرة داخل النافذة |
| **الرسائل المرسلة** | إجمالي الرسائل الصادرة |
| **الرسائل المُسلَّمة** | الرسائل التي تم تسليمها بنجاح |
| **الرسائل المقروءة** | الرسائل التي قرأها المستلمون |

### سرد حسابات Meta للتحليلات

**Endpoint:** `GET /api/analytics/meta/accounts`

عرض حسابات Meta التي تتوفر لها بيانات تحليلات.

### تحديث ذاكرة التخزين المؤقت لتحليلات Meta

**Endpoint:** `POST /api/analytics/meta/refresh`

فرض جلب جديد من واجهة برمجة تطبيقات Meta. يتم تخزين النتائج مؤقتاً في Redis للأداء.

## الأدوات المخصصة

إنشاء أدوات تحليلات مخصصة لعرض المقاييس المهمة لمؤسستك.

### سرد الأدوات

**Endpoint:** `GET /api/widgets`

عرض جميع الأدوات المخصصة المكونة لمؤسستك.

### إنشاء أداة

**Endpoint:** `POST /api/widgets`

```json
{
  "name": "Daily Active Contacts",
  "type": "counter",
  "query": {
    "table": "contacts",
    "aggregation": "count",
    "filters": {
      "date_field": "created_at",
      "period": "today"
    }
  },
  "config": {
    "color": "blue",
    "icon": "users"
  }
}
```

### أنواع الأدوات

| النوع | الوصف |
|------|-------------|
| **Counter** | قيمة رقمية واحدة |
| **Chart** | رسم بياني خطي أو شريطي للسلاسل الزمنية |
| **Table** | عرض بيانات جدولي |
| **Gauge** | مقياس قائم على النسبة المئوية |

### الحصول على بيانات الأداة

**Endpoint:** `GET /api/widgets/{id}/data`

تنفيذ استعلام الأداة وإرجاع بيانات منسقة للعرض.

### الحصول على جميع بيانات الأدوات

**Endpoint:** `GET /api/widgets/data`

جلب بيانات جميع الأدوات في طلب واحد لعرض لوحة المعلومات.

### حفظ تخطيط الأدوات

**Endpoint:** `POST /api/widgets/layout`

حفظ ترتيب وحجم الأدوات على لوحة المعلومات الخاصة بك:

```json
{
  "layout": [
    { "widget_id": "widget-1", "x": 0, "y": 0, "w": 4, "h": 2 },
    { "widget_id": "widget-2", "x": 4, "y": 0, "w": 4, "h": 2 }
  ]
}
```

### الحصول على مصادر البيانات

**Endpoint:** `GET /api/widgets/data-sources`

سرد جميع مصادر البيانات المتاحة التي يمكن استعلامها بواسطة الأدوات المخصصة.

## ميزات المقارنة

مقارنة المقاييس عبر فترات زمنية أو أبعاد مختلفة:

| المقارنة | الوصف |
|------------|-------------|
| **مقارنة الفترات** | مقارنة هذا الأسبوع بالأسبوع الماضي، هذا الشهر بالشهر الماضي |
| **وكيل مقابل وكيل** | مقارنة أداء الوكلاء جنباً إلى جنب |
| **مثيل مقابل مثيل** | مقارنة الأداء عبر مثيلات واتساب |
| **قالب مقابل قالب** | مقارنة استخدام القوالب ومعدلات التسليم |
