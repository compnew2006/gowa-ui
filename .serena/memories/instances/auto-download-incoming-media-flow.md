Auto-download incoming media has two critical seams. Backend instance updates should merge partial `settings` payloads with the stored JSON before calling `pkg/whatsmeow.EnsureInstanceSettingsDefaults` and `ValidateInstanceSettings`; otherwise single-setting updates risk wiping unrelated keys and are more brittle against legacy instance rows. Frontend browser prefetch is driven from `frontend/src/services/websocket.ts` via `maybeAutoDownloadIncomingMedia(payload)` and should remain independent from whether `contactsStore.addMessage()` appended the message into the active thread. The toggle handler in `frontend/src/views/settings/InstancesView.vue` should catch update failures locally and refresh the instance instead of letting the rejected promise crash the page.
