# <div dir="rtl">جهات الاتصال</div>

أدِر جهات اتصال واتساب الخاصة بك، ونظّمها باستخدام الفلاتر والعلامات، وعيّنها لأعضاء الفريق، وتعاون عبر فريقك.

## عرض جهات الاتصال

**نقطة النهاية:** `GET /api/contacts`

اعرض جميع جهات الاتصال في مؤسستك. تتضمن القائمة رقم الهاتف والاسم والعلامات ووقت آخر رسالة وعدد الرسائل غير المقروءة لكل جهة اتصال.

### التصفية

قم بتضييق جهات الاتصال باستخدام هذه الفلاتر:

| الفلتر | الوصف | مثال |
|--------|-------------|---------|
| **البحث** | مطابقة حسب الهاتف أو الاسم أو اسم الملف الشخصي | `?search=john` |
| **العلامات** | تصفية حسب العلامات المعينة | `?tags=vip,lead` |
| **وضع العلامة** | مطابقة كل أو أي علامة | `?tag_mode=all` أو `?tag_mode=any` |
| **معينة لـ** | تصفية حسب المستخدم المعيّن | `?assigned_to=user-id` |
| **الحالة** | دردشات مفتوحة أو مغلقة أو قيد الانتظار | `?status=open` |
| **النطاق الزمني** | تصفية حسب آخر نشاط | `?from=2024-01-01&to=2024-12-31` |

### عرض الوكيل

إذا كان لديك دور **الوكيل**، فإنك ترى فقط جهات الاتصال التي يمكنك الوصول إليها:

- الدردشات المعينة لك
- الدردشات العامة (`is_public = true`)
- الدردشات التي أنت متعاون فيها

يرى المديرون والمدراء جميع جهات الاتصال في المؤسسة.

## إنشاء جهة اتصال

**نقطة النهاية:** `POST /api/contacts`

```json
{
  "phone_number": "+1234567890",
  "name": "John Doe",
  "tags": ["vip", "customer"],
  "metadata": {
    "source": "website"
  }
}
```

**التحقق:**

- يتم التحقق من تنسيق رقم الهاتف تلقائياً
- يتم منع أرقام الهواتف المكررة داخل نفس المؤسسة
- يتم إرسال webhook `contact_created` عند النجاح

### بدء دردشة جديدة (WhatsMeow)

إذا كانت مؤسستك تستخدم مزود WhatsMeow، يمكنك بدء دردشة مباشرة مع أي رقم هاتف:

1. أدخل رقم الهاتف في مربع حوار بدء الدردشة
2. يتحقق النظام من أن الرقم موجود على واتساب
3. إذا تم التحقق، يتم إنشاء جهة الاتصال وتفتح الدردشة
4. إذا كان الرقم عملاً موثقاً، يتم حل اسم العمل تلقائياً

## عرض جهة اتصال

**نقطة النهاية:** `GET /api/contacts/{id}`

اعرض تفاصيل جهة الاتصال الكاملة بما في ذلك معلومات الملف الشخصي والعلامات وسجل التعيين والبيانات الوصفية.

### بيانات الجلسة

**نقطة النهاية:** `GET /api/contacts/{id}/session-data`

تعرض عرضاً موحداً لنشاط جهة الاتصال الأخير:

- الرسائل الأخيرة
- العلامات المطبقة
- ملاحظات المحادثة
- سجل التعيين

## تحديث جهة اتصال

**نقطة النهاية:** `PUT /api/contacts/{id}`

قم بتحديث أي حقل قابل للتعديل:

```json
{
  "name": "Jane Doe",
  "tags": ["vip", "priority"],
  "metadata": {
    "source": "referral"
  }
}
```

## تعيين جهات الاتصال

**نقطة النهاية:** `PUT /api/contacts/{id}/assign`

عيّن جهة اتصال لعضو فريق معين:

```json
{
  "user_id": "user-uuid"
}
```

**ما يحدث:**

1. يتم تعيين جهة الاتصال للمستخدم المحدد
2. يتلقى المستخدم إشعاراً فورياً عبر WebSocket
3. يتم إرسال webhook `contact_assigned`

## المتعاونون

ادعُ أعضاء فريق آخرين للتعاون في جهة اتصال.

### عرض المتعاونين

**نقطة النهاية:** `GET /api/contacts/{id}/collaborators`

### دعوة متعاون

**نقطة النهاية:** `POST /api/contacts/{id}/collaborators`

```json
{
  "user_id": "user-uuid"
}
```

يتلقى المستخدم المدعو إشعاراً ويمكنه القبول أو الرفض.

### قبول / رفض

- **قبول:** `PUT /api/contacts/{id}/collaborators/{user_id}/accept`
- **رفض:** `PUT /api/contacts/{id}/collaborators/{user_id}/decline`

### إزالة متعاون

**نقطة النهاية:** `DELETE /api/contacts/{id}/collaborators/{user_id}`

## الحذف الناعم

**نقطة النهاية:** `POST /api/contacts/{id}/soft-delete`

إخفاء جهة اتصال من عرضك دون حذفها للمتعاونين الآخرين. تبقى جهة الاتصال مرئية لأعضاء الفريق الآخرين الذين لديهم صلاحية الوصول.

## حذف جهة اتصال

**نقطة النهاية:** `DELETE /api/contacts/{id}`

يزيل جهة الاتصال وجميع البيانات المرتبطة بها بشكل دائم. يتطلب هذا الإجراء صلاحية `contacts:delete`.

## إصلاح جهات الاتصال

يمكن إصلاح سجلات جهات الاتصال اليتيمة أو غير المتسقة تلقائياً. يحدث هذا عادةً بعد ترحيلات البيانات أو تغييرات الحساب:

1. يفحص النظام جهات الاتصال ذات المراجع المفقودة أو غير الصالحة
2. يتم إعادة تعيين جهات الاتصال اليتيمة إلى الحساب أو المثيل الصحيح
3. يتم تحديث البيانات الوصفية لجهة الاتصال لتعكس الحالة الحالية
4. يتم تسجيل جميع إجراءات الإصلاح
