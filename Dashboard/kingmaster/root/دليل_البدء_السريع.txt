📋 الخطوات المطلوبة للتشغيل:

┌─────────────────────────────────────────────────────────────┐
│ 1️⃣  تشغيل XAMPP                                            │
└─────────────────────────────────────────────────────────────┘
   • افتح XAMPP Control Panel
   • شغّل Apache
   • شغّل MySQL
   • تأكد أن الإشارة الضوئية خضراء

┌─────────────────────────────────────────────────────────────┐
│ 2️⃣  استيراد قاعدة البيانات                                │
└─────────────────────────────────────────────────────────────┘
   • افتح: http://localhost/phpmyadmin
   • اختر قاعدة البيانات الموجودة (أو أنشئ واحدة جديدة)
   • اذهب لتبويب "Import"
   • اختر الملف: database/products_table.sql
   • اضغط "Go"
   • ✅ انتهى!

┌─────────────────────────────────────────────────────────────┐
│ 3️⃣  التحقق من إعدادات الاتصال                             │
└─────────────────────────────────────────────────────────────┘
   افتح الملفات التالية وتأكد من البيانات:
   
   ✓ api/get_products.php
   ✓ api/manage_product.php
   
   يجب أن تكون:
   ┌───────────────────────────────────────┐
   │ $servername = "localhost";            │
   │ $username = "root";                   │
   │ $password = "";                       │
   │ $dbname = "kingmaster";  ← اسم قاعدتك│
   └───────────────────────────────────────┘

┌─────────────────────────────────────────────────────────────┐
│ 4️⃣  تشغيل النظام                                           │
└─────────────────────────────────────────────────────────────┘
   
   📱 صفحة عرض المنتجات:
   ➜ http://localhost/test/products.html
   
   🎛️ لوحة التحكم (إدارة المنتجات):
   ➜ http://localhost/test/admin_products.html

═══════════════════════════════════════════════════════════════

💡 نصائح سريعة:

✨ لإضافة منتج جديد:
   1. افتح لوحة التحكم
   2. اضغط "إضافة منتج"
   3. املأ البيانات المطلوبة
   4. اضغط "حفظ"

🎨 لإضافة ألوان ومقاسات:
   • تأكد أن المنتج ليس رقمياً
   • أضف اللون بالاسم والكود
   • أضف المقاسات (S, M, L, XL...)

🏷️ لإضافة خصم:
   • اكتب نسبة الخصم في حقل "نسبة الخصم"
   • السعر النهائي سيُحسب تلقائياً

⚠️ حل المشاكل الشائعة:

❌ المشكلة: لا تظهر المنتجات
   ✅ الحل:
      1. افتح F12 في المتصفح
      2. تحقق من Console
      3. تأكد من استيراد قاعدة البيانات
      4. تأكد من تشغيل MySQL

❌ المشكلة: خطأ في الاتصال بقاعدة البيانات
   ✅ الحل:
      1. تأكد من تشغيل MySQL في XAMPP
      2. راجع بيانات الاتصال في ملفات API
      3. تأكد من اسم قاعدة البيانات صحيح

❌ المشكلة: الصور لا تظهر
   ✅ الحل:
      استخدم روابط صور صالحة مثل:
      https://via.placeholder.com/400x300
