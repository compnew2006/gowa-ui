## Overview

Templates are reusable message blueprints stored in your organization. They are managed directly via this API — there is no external approval workflow. A template belongs to a WhatsApp account, has a name, language, category, and optional header/body/footer content and buttons.

Templates are sent to contacts through the [Send Template Message](/api-reference/messages/#send-template-message) endpoint, the chat composer, or campaigns.

## List Templates

Retrieve all templates for your organization.

```bash
GET /api/templates
```

Requires the `templates:read` permission.

### Query Parameters

| Parameter | Type | Description |
|-----------|------|-------------|
| `page` | integer | Page number (default: 1) |
| `limit` | integer | Items per page (default: 50, max: 100) |
| `account` | string | Filter by WhatsApp account name |
| `category` | string | Filter by category (MARKETING, UTILITY, AUTHENTICATION) |
| `search` | string | Case-insensitive partial match on name or display name |

### Response

  "status": "success",
  "data": {
    "templates": [
      {
        "id": "uuid",
        "whatsapp_account": "My Business Account",

        "buttons": [],
        "sample_values": [],

## Create Template

Create a new template.

```bash
POST /api/templates
```

Requires the `templates:write` permission.

### Request Body

```json
{
  "whatsapp_account": "My Business Account",
  "name": "welcome message",
  "display_name": "Welcome Message",
  "language": "en",
  "category": "MARKETING",
  "header_type": "TEXT",
  "header_content": "Hi {{1}}",
  "body_content": "Welcome to our store, {{1}}! Use code {{2}} for 10% off your first order.",
  "footer_content": "Reply STOP to unsubscribe",
  "buttons": [],
  "sample_values": [],
  "add_security_recommendation": false,
  "code_expiration_minutes": 0
}
```

| Field | Type | Required | Description |
|-------|------|----------|-------------|
| `whatsapp_account` | string | Yes | Name of the WhatsApp account the template belongs to |
| `name` | string | Yes | Template name. Normalized to lowercase with spaces/hyphens converted to underscores |
| `display_name` | string | No | Human-friendly display name |
| `language` | string | Yes | Language code (e.g. `en`) |
| `category` | string | No | `MARKETING`, `UTILITY`, or `AUTHENTICATION` |
| `header_type` | string | No | `TEXT`, `IMAGE`, `VIDEO`, `DOCUMENT`, or `NONE` |
| `header_content` | string | No | Header content. TEXT headers may contain at most one `{{variable}}` |
| `body_content` | string | Yes | Main message content with `{{1}}`, `{{2}}` or named `{{var}}` placeholders |
| `footer_content` | string | No | Optional footer text |
| `buttons` | array | No | Button definitions (quick reply, URL, phone number) |
| `sample_values` | array | No | Sample values for variable placeholders |
| `add_security_recommendation` | boolean | No | Authentication templates only: add "For your security, do not share this code." |
| `code_expiration_minutes` | integer | No | Authentication templates only: code expiration in minutes (1–90). 0 = no expiration footer |

The `name` + `language` combination must be unique per account — creating a duplicate returns `409 Conflict`.

### Response

```json
{
  "status": "success",
  "data": {
    "id": "uuid",
    "whatsapp_account": "My Business Account",
    "name": "welcome_message",
    "display_name": "Welcome Message",
    "language": "en",
    "category": "MARKETING",
    "header_type": "TEXT",
    "header_content": "Hi {{1}}",
    "body_content": "Welcome to our store, {{1}}! Use code {{2}} for 10% off your first order.",
    "footer_content": "Reply STOP to unsubscribe",
    "buttons": [],
    "sample_values": [],
    "add_security_recommendation": false,
    "code_expiration_minutes": 0,
    "created_at": "2024-01-01T00:00:00Z",
    "updated_at": "2024-01-01T00:00:00Z"
  }
}
```

## Update Template

Update an existing template. All fields are optional — only the provided fields are updated.

```bash
PUT /api/templates/{id}
```

Requires the `templates:write` permission. Returns `404` if the template does not exist.

### Request Body

```json
{
  "body_content": "Welcome, {{1}}! Use code {{2}} for 15% off your first order."
}
```

### Response

Returns the updated template in the same shape as [Create Template](#create-template).

## Delete Template

Delete a template (soft delete — the row remains in the database with a deleted timestamp).

```bash
DELETE /api/templates/{id}
```

Requires the `templates:delete` permission. Returns `404` if the template does not exist.

### Response

```json
{
  "status": "success",
  "data": {
    "message": "Template deleted successfully"
  }
}
```

## Template Variables

### Positional Parameters

Use `{{1}}`, `{{2}}`, etc. for dynamic content:

```
Hello {{1}}, your order #{{2}} is ready for pickup at {{3}}.
```

### Named Parameters

Templates also support named parameters for better readability:

```
Hello {{customer_name}}, your order #{{order_id}} is ready for pickup at {{store_location}}.
```

Whatomato detects automatically whether a template uses positional or named parameters — no configuration needed.

### Header Variables

A TEXT header can contain **at most one** variable — a Meta restriction enforced at creation time. Both positional (`{{1}}`) and named (`{{season}}`) forms work, but mixing positional and named variables within the same template is not allowed.

When sending, provide the header value via the `header_params` field on [Send Template Message](/api-reference/messages/#send-template-message). It falls back to `template_params` if omitted.

### URL Button Parameters

Templates can include URL buttons with dynamic variables. For example, a "Track Order" button with URL `https://example.com/track/{{1}}`.

When sending a template with dynamic URL buttons, provide the dynamic values via the `button_params` field on [Send Template Message](/api-reference/messages/#send-template-message). The key is the zero-based button index:

```json
{
  "template_name": "order_shipped",
  "template_params": { "1": "John", "2": "12345" },
  "button_params": { "0": "12345" }
}
```
