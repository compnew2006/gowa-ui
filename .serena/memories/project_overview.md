Whatomate is a modern open-source WhatsApp business platform with a Go backend and Vue 3 frontend. It supports WhatsApp Cloud API and WhatsMeow/WhatsApp Web, multi-tenant organizations, real-time chat, automation/chatbot flows, campaigns, templates, analytics, and role-based permissions. The main backend entrypoint is `cmd/whatomate`; production builds embed the frontend into the Go binary. Repo layout: `cmd/` entrypoints, `internal/` backend packages and handlers, `pkg/` shared/backend services, `frontend/` Vue 3 app, `docs/` deployment and product docs, `mcp-server/` auxiliary tooling.
