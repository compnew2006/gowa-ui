# Analytics

Track performance across all Whatomate features with comprehensive dashboards, message analytics, chatbot metrics, agent performance reports, and custom widgets.

## Dashboard Overview

**Endpoint:** `GET /api/analytics/dashboard`

The dashboard provides a high-level summary of your organization's activity:

- **Total contacts** — Number of unique contacts in your organization
- **Total messages** — All messages sent and received
- **Open chats** — Currently active conversations
- **Today's activity** — Messages, contacts, and chats created today
- **Average response time** — How quickly agents respond to messages

## Message Analytics

**Endpoint:** `GET /api/analytics/messages`

Detailed breakdown of messaging activity over a date range:

```
GET /api/analytics/messages?from=2024-01-01&to=2024-12-31
```

### Metrics

| Metric | Description |
|--------|-------------|
| **Total sent** | Outbound messages sent |
| **Total received** | Inbound messages received |
| **Delivery rate** | Percentage of messages successfully delivered |
| **Read rate** | Percentage of messages read by recipients |
| **Failure rate** | Percentage of messages that failed to send |

### Grouping

Messages are grouped by:

| Dimension | Description |
|-----------|-------------|
| **Type** | Text, media, template, interactive |
| **Direction** | Inbound or outbound |
| **Status** | Pending, sent, delivered, read, failed |
| **Date** | Time-series data for trend analysis |

### Instance Filter

Filter analytics by specific WhatsApp instance to compare performance across accounts.

## Chatbot Analytics

**Endpoint:** `GET /api/analytics/chatbot`

Measure the effectiveness of your chatbot automation:

| Metric | Description |
|--------|-------------|
| **Total sessions** | Number of chatbot sessions created |
| **AI responses** | Messages generated by the AI provider |
| **Agent transfers** | Conversations transferred from chatbot to human agents |
| **Resolution rate** | Percentage of sessions resolved without agent transfer |
| **Keyword usage** | Which keyword rules matched most frequently |
| **Flow usage** | Which conversation flows were activated most |

### Keyword Performance

View which keyword rules are triggered most often and their effectiveness at resolving queries without agent intervention.

### Flow Performance

Track how many conversations complete each flow versus dropping off or requiring agent transfer.

## Agent Analytics

**Endpoint:** `GET /api/analytics/agents`

Performance metrics for each agent in your organization:

| Metric | Description |
|--------|-------------|
| **Chats handled** | Total conversations managed by the agent |
| **Messages sent** | Outbound messages sent by the agent |
| **Average response time** | Time from inbound message to agent reply |
| **Average resolution time** | Time from chat open to chat close |
| **Customer ratings** | Satisfaction ratings received on closed chats |

### Agent Details

**Endpoint:** `GET /api/analytics/agents/{id}`

View detailed metrics for a specific agent, including:

- Daily/weekly/monthly activity trends
- Chat volume over time
- Response time distribution
- Resolution time distribution

### Agent Comparison

**Endpoint:** `GET /api/analytics/agents/comparison`

Compare multiple agents side by side:

| Agent | Chats | Avg Response | Avg Resolution | Rating |
|-------|-------|--------------|----------------|--------|
| Alice | 150 | 2.3 min | 18 min | 4.8 |
| Bob | 120 | 3.1 min | 22 min | 4.5 |
| Carol | 95 | 1.8 min | 15 min | 4.9 |

### Export Agent Ratings

**Endpoint:** `GET /api/analytics/agents/ratings/export`

Download a CSV or JSON file of all customer satisfaction ratings for external analysis.

## Meta Analytics

**Endpoint:** `GET /api/analytics/meta`

> **Note:** Requires the Meta (Cloud API) provider.

Fetch conversation and messaging metrics directly from Meta's analytics API:

| Metric | Description |
|--------|-------------|
| **Conversations started** | New 24-hour conversation windows |
| **Conversations continued** | Ongoing conversations within the window |
| **Messages sent** | Total outbound messages |
| **Messages delivered** | Successfully delivered messages |
| **Messages read** | Messages read by recipients |

### List Meta Accounts for Analytics

**Endpoint:** `GET /api/analytics/meta/accounts`

View which Meta accounts have analytics data available.

### Refresh Meta Analytics Cache

**Endpoint:** `POST /api/analytics/meta/refresh`

Force a fresh fetch from Meta's API. Results are cached in Redis for performance.

## Custom Widgets

Create custom analytics widgets to display the metrics that matter to your organization.

### List Widgets

**Endpoint:** `GET /api/widgets`

View all custom widgets configured for your organization.

### Create Widget

**Endpoint:** `POST /api/widgets`

```json
{
  "name": "Daily Active Contacts",
  "type": "counter",
  "query": {
    "table": "contacts",
    "aggregation": "count",
    "filters": {
      "date_field": "created_at",
      "period": "today"
    }
  },
  "config": {
    "color": "blue",
    "icon": "users"
  }
}
```

### Widget Types

| Type | Description |
|------|-------------|
| **Counter** | Single numeric value |
| **Chart** | Time-series line or bar chart |
| **Table** | Tabular data display |
| **Gauge** | Percentage-based gauge |

### Get Widget Data

**Endpoint:** `GET /api/widgets/{id}/data`

Execute the widget's query and return formatted data for rendering.

### Get All Widgets Data

**Endpoint:** `GET /api/widgets/data`

Fetch data for all widgets in a single request for dashboard rendering.

### Save Widget Layout

**Endpoint:** `POST /api/widgets/layout`

Save the arrangement and sizing of widgets on your dashboard:

```json
{
  "layout": [
    { "widget_id": "widget-1", "x": 0, "y": 0, "w": 4, "h": 2 },
    { "widget_id": "widget-2", "x": 4, "y": 0, "w": 4, "h": 2 }
  ]
}
```

### Get Data Sources

**Endpoint:** `GET /api/widgets/data-sources`

List all available data sources that can be queried by custom widgets.

## Comparison Features

Compare metrics across different time periods or dimensions:

| Comparison | Description |
|------------|-------------|
| **Period-over-period** | Compare this week vs. last week, this month vs. last month |
| **Agent vs. agent** | Side-by-side agent performance comparison |
| **Instance vs. instance** | Compare performance across WhatsApp instances |
| **Template vs. template** | Compare template usage and delivery rates |
